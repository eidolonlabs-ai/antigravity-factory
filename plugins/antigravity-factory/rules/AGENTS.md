# Antigravity Factory Rules

Operate this workspace with the **Antigravity Factory** multi-agent workflow. Apply these five rules to every feature, bugfix, or refactor:

1. **Plan Before Building (Shift-Left Pushback)**: Never jump straight into multi-file edits on non-trivial tasks. Route the entry point with `factory-intake`—pushing back (`needs_clarification`) when requirements, error handling, or the 4-Part State & Edge-Case Matrix are incomplete (`/grill-me` + read-only `factory-architect`). Inventory the repository (`agy-factory detect`), and freeze contracts, Milestone 1.5 tests, and explicit disjoint file ownership with `factory-plan` (`.factory/spec.json` via `agy-factory plan --init`, or `/plan`) before writing code.
2. **Isolate Parallel Work**: When executing slices in parallel (`factory-build`), give each `factory-builder` an isolated git worktree (via Antigravity `swarm` / `/teamwork` `workspace: "share"` / `"branch"`, or `git worktree add` with `FACTORY_SLICE=<slice>`) and strictly disjoint owned files. Never assign two concurrent builders to edit the same file, enforce slice ownership mechanically with `agy-factory audit-diff --slice <slice>` (or `--allow-paths "<slice-globs>"`), and land verified slices with `agy-factory land --worktree <dir> --slice <slice>`.
3. **Deterministic Verification First**: Run `factory-verify` (`agy-factory verify --require-tests` or the repository's build, lint, typecheck, and test commands) before declaring work complete. Never treat `NOT_RUN` as `PASS`—an unconfigured or skipped test suite is unverified, not green. Never forge or hand-edit `.factory/verify-receipt.json` or modify protected `holdout/` test suites. When changes affect a web UI, verify live user flows and console/network health using the `browser` subagent (Antigravity) or automated Playwright/headless E2E browser checks.
4. **Independent Diff & Security Review**: Run `factory-review` (`agy-factory audit-diff` to catch secrets and injection sinks deterministically, followed by a cold-context read-only semantic review of `git diff` via `factory-reviewer`, Antigravity's read-only `research` subagent, enforcing **Reproduce Before Fixing**) and conclude with `factory-status` before marking a task done.
5. **Preserve Documentation**: Keep existing comments, docstrings, type annotations, and user-facing documentation intact unless they are directly invalidated by the change.

## Local factory scope

Use one agent for small changes and native Antigravity delegation/browser features when useful. Do not build a second scheduler or change host permissions automatically. Verification receipts are unsigned freshness records; protected holdouts are not hidden. Required evidence is recorded only after actual checks, using captured digests through the CLI. Conclude with `agy-factory status --json` and a separate review/QA report. Bounded stop exhaustion means incomplete work, never success.
